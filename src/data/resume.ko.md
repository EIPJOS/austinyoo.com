## 요약

물류·창고 운영, 계약 및 데이터베이스 관리, 독립 소프트웨어 개발 경험을 갖춘 계산 데이터 과학(Computational Data Sciences) 전공 졸업생입니다. 데이터 수집부터 배포까지, 자동화된 실서비스 수준의 데이터 파이프라인과 웹 애플리케이션을 직접 구축하고 운영합니다. 국제 물류와 통관 분야의 현장 경험에 클라우드 인프라, 백엔드 자동화, 응용 AI 역량을 더했습니다.

## 경력

### 스태프 인턴 — JCS Systems Inc., 미국 조지아
*2024년 6월 – 2024년 8월*

- 현대글로비스 물류센터의 선임 직원들과 협업해 운영 업무 흐름을 개선했습니다.
- 현대트랜시스 물류센터의 선임 직원들과 협력해 재고 관리 체계를 개선했습니다.
- 재고 현황을 점검하고 일일 수급 요구사항을 보고하며 재고 품질을 관리했습니다.
- 비상 상황에서 추가 업무를 지원하며 책임감과 팀워크를 보여주었습니다.

### 총괄 매니저 · 데이터베이스 관리자 — JNB 관세사무소(JNB Customs), 대한민국
*2023년 9월 – 2024년 1월*

- 서류를 처리 우선순위에 따라 기록하고 체계적으로 정리했습니다.
- 신규 프로젝트 제안을 평가하고, 회사 목표와의 부합 여부를 보고했습니다.
- 제휴 파트너와의 계약을 관리하며 계약 조건과 목표 이행을 확인했습니다.

## 개인 프로젝트

### usgridexplorer.com — 미국 전력망 및 데이터센터 인프라 플랫폼
*2025년 – 현재*

- 미국 전력망 용량과 데이터센터 개발 현황을 추적하는 완전 자동화 콘텐츠·데이터 플랫폼을 구축해 운영하고 있으며, 디스플레이 광고로 수익화하고 있습니다.
- RSS 피드를 수집해 Supabase에 저장하고, GitHub Actions 일정에 맞춰 Vercel 서버리스 함수로 제공하는, AI 작성 리서치 브리핑 자동 발행 파이프라인을 처음부터 끝까지 설계했습니다.
- 기술 스택: React, Vite, Supabase (PostgreSQL), Vercel, GitHub Actions, Anthropic API.

### CustomsMate KR — 한국 수출입 규정 검색 플랫폼
*2025년 – 현재*

- 관세청, 식약처(MFDS), 법제처의 공공데이터를 모아 관세사와 수출입 기업이 검색할 수 있는 플랫폼을 구축하고 있습니다.
- GitHub Actions 스케줄 작업으로 Supabase에 데이터를 자동 수집하고, AI가 생성한 쉬운 한국어 규정 요약을 React/Vite 프론트엔드로 제공합니다.

### Grid Permit Alerts — B2B 데이터센터 허가 추적 서비스
*2025년 – 현재*

- 북부 버지니아의 데이터센터 개발 허가 신청 현황을 추적해 상업용 부동산 중개인, 벤더 영업팀, 투자자에게 알려주는 구독형 알림 서비스를 개발하고 있습니다.
- usgridexplorer.com의 기존 방문자를 고객 유입과 유통 채널로 활용합니다.
